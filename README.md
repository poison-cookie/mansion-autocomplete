# サイト別入力候補オートコンプリート

通常の `autocomplete` が効かないサイトでも、入力欄にサイト専用の候補を表示して選択できる Tampermonkey 用ユーザースクリプトです。会社名、担当者名、施設名、物件名など、よく使う文字列を登録できます。

例えば、イタンジ用に登録した候補はイタンジだけで表示され、別サイトには出ません。

## 使う拡張機能

Chrome では Tampermonkey か Violentmonkey のような「ユーザースクリプト管理」拡張機能を使います。まずは Tampermonkey が分かりやすいです。

## 導入手順

1. Chrome ウェブストアから Tampermonkey を入れる
2. Tampermonkey のダッシュボードを開く
3. 「新規スクリプト」を作成する
4. `mansion-autocomplete.user.js` の中身を全部貼り付けて保存する
5. 対象サイトを再読み込みする

## 使い方

- 入力欄にフォーカスすると候補が表示されます。
- 候補行クリック、`Enter`、`Tab` で入力欄へ反映します。
- 候補名の右横の `☆` / `★` で、候補を上位固定できます。
- 候補名の右横のコピーアイコンは、入力欄へ反映してクリップボードへコピーします。
- 候補右側の `…` から、その候補を削除できます。
- ポップアップ下部の `入力をクリア ×` で、入力欄の文字だけを空にできます。
- `Esc` で候補を閉じます。

## 設定画面

ページ右下の `設 定` ボタンから設定画面を開けます。

`設 定` ボタンはドラッグで好きな位置へ移動できます。移動した位置は保存され、次回以降も同じ場所に表示されます。

- `このサイト`: 現在サイトだけ機能を有効/無効にします。
- `入力モード`: 通常は `標準`。反映されないサイトでは `キーボード入力風` を試します。
- `Chrome候補抑制`: Chrome標準候補を出にくくします。
- `使用回数データ上限`: 使用回数データを1サイトあたり `500` / `1,000` / `3,000` / `5,000` / `10,000` 件から選べます。標準は `5,000` 件です。

## このサイトの候補

設定画面の `このサイトの候補を追加` から、現在開いているサイトだけで使う候補を追加できます。

候補はサイトごとに分かれます。候補数や内容がサイトごとに違う場合でも、別サイトへ混ざりません。

フォーム送信、または `検索` / `決定` / `確定` などのボタンを押した名前も、自動で `このサイトの候補` に追加されます。使用回数は候補の並び順に使います。

設定画面の `このサイトの候補` には検索ボックスがあります。候補が多い場合でも、登録済み候補を絞り込んでピン止めや削除ができます。

## CSV一括登録

設定画面の `このサイト候補CSV一括登録` から、よく使う入力候補をまとめて現在サイトの候補に追加できます。

CSVは `name` 列があればその列を読み、なければ1列目を読みます。空行と重複は自動で除外されます。候補名セル内に改行が含まれる行はスキップし、取り込み後にスキップ行番号を表示します。

文字コードは UTF-8、UTF-8 BOM付き、UTF-16、Shift-JIS/CP932 のCSVを自動判定して読み込みます。Excelで保存した日本語CSVでも文字化けしにくいようにしています。文字化けを示す `�` が候補名に含まれる行は登録せず、スキップ行として表示します。

例:

```csv
name
中野ブロードウェイ
パークハウス板橋
グランドメゾン恵比寿
```

`このサイトの候補をCSVエクスポート` で、現在サイトの候補をCSV保存できます。CSVには `name`、`count`、`lastUsed`、`pinned` を出力するため、検索で増えた候補、使用回数、ピン止め状態も一緒にバックアップできます。

## JSON移行

設定画面右上の `移行`、または Tampermonkey メニューの `移行画面を開く` から、全サイト横断のJSON移行画面を開けます。

JSONエクスポートでは、出力するサイトをチェックで選べます。候補名は常に含まれ、必要に応じて `ピン止め`、`使用履歴`、`基本設定` を含められます。エクスポート前には、対象サイト数、候補数、ピン止め件数、使用履歴の有無、基本設定の有無をプレビュー表示します。社内共有では、個人の利用傾向が入る `使用履歴` は外して出力するのがおすすめです。

JSONインポートでは、JSONを選択してもすぐには取り込みません。まず対象サイト数、候補数、ピン止め件数、使用履歴、基本設定の有無を確認画面に表示し、`この内容をインポート` を押した時だけ取り込みます。既存データは消さずにマージします。候補とピン止めは重複を除いて追加し、使用履歴を取り込む場合は使用回数は大きい方、最終使用日は新しい方を残します。

## 候補の並び順

候補は次の順で表示されます。

1. ピン止めしたもの
2. 入力文字と完全一致・前方一致するもの
3. 入力文字をそのまま含むもの
4. 複数キーワードが近い位置・正しい順序で含まれるもの
5. 使用回数が多いもの
6. 最近使ったもの
7. 候補名の五十音順

`中野 ブロード` のようにスペースで区切ると、両方の語を含む候補だけを表示します。全角/半角、空白、ハイフン、中点、長音、ひらがな/カタカナなどの表記ゆれは検索時に吸収します。

候補を入力欄へ入れただけでは使用回数は増えません。フォーム送信、または `検索` / `決定` / `確定` などのボタンを押したタイミングで +1 します。

## Tampermonkey メニュー

- `設定画面を開く`: 候補と履歴を画面で管理する
- `移行画面を開く`: 全サイト分の候補や設定をJSONで移行する
- `このサイトで有効/無効を切り替え`: 現在のサイトだけ機能をオン/オフする。サイトで無効にするとページ上の `設 定` ボタンも非表示になるため、再び有効にする時はこのTampermonkeyメニューを使います。
- `このサイトの候補を編集`: 1行に1つずつ候補を入力
- `このサイトの候補を初期化`: 現在サイトの候補を空にし、使用回数もリセットする
- `このサイトの使用回数をリセット`: 候補名は残したまま、使用回数と最終使用日だけをリセットする

ピン止めは、ポップアップ内または設定画面の候補一覧にある `☆` / `★` でON/OFFできます。

設定画面の `すべて削除` は、今開いているサイトの候補、使用回数、ピン止め状態をまとめて削除します。

## 厳しいサイト向けの考慮

イタンジのように React/Vue などで入力欄を制御しているサイトでも反映されやすいように、値のセット時は通常の代入ではなくブラウザ標準の setter と `InputEvent` / `change` イベントを使っています。

iframe 内の入力欄でも動くように `@all-frames true` を付けています。Tampermonkey 側ではページ本体へ直接注入せず、content script 側で動く設定にしています。

日本語入力の変換中は候補表示を一時停止し、変換確定後に候補を出し直します。

このスクリプトの候補ポップアップと設定画面は Shadow DOM 内に作成します。サイト側の CSS の影響を受けにくく、逆にこのスクリプトの CSS がサイト側レイアウトへ影響しにくい構成です。

## 注意

- Chrome 標準の保存済みオートコンプリート履歴は、Tampermonkey から直接読み取れません。
- Chrome ウェブストア、ブラウザ設定画面、拡張機能の実行が禁止された業務画面では動作しません。
- ログイン後の一部画面が別ドメイン iframe の場合、そのドメインでも Tampermonkey の実行許可が必要です。
