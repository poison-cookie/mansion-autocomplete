# マンション名オートコンプリート

通常の `autocomplete` が効かないサイトでも、入力欄に独自の候補を表示して選択できる Tampermonkey 用ユーザースクリプトです。

例えば候補リストや入力履歴に `パークハウス板橋`、`パークハウス松濤` がある場合、`パークハウス` と入力するとそれらが候補に表示されます。

## 使う拡張機能

Chrome では Tampermonkey か Violentmonkey のような「ユーザースクリプト管理」拡張機能を使います。まずは Tampermonkey が分かりやすいです。

## 導入手順

1. Chrome ウェブストアから Tampermonkey を入れる
2. Tampermonkey のダッシュボードを開く
3. 「新規スクリプト」を作成する
4. `mansion-autocomplete.user.js` の中身を全部貼り付けて保存する
5. 対象サイトを再読み込みする

## 使い方

入力欄にフォーカスすると候補が表示されます。

- `↑` / `↓`: 候補を選択
- `Enter` / `Tab`: 決定
- マウスクリック: 決定
- 候補名の右横のコピーアイコン: 入力欄へ反映してクリップボードへコピー
- 候補右側のゴミ箱: その候補を削除
- `Esc`: 閉じる

ページ右下の `設定` ボタンから設定画面を開けます。設定画面では、手動候補の追加・削除、このサイトの履歴削除、全サイトの履歴削除ができます。

設定画面では入力モードも切り替えできます。

- `標準`: 通常はこちら。React/Vue 系の入力欄に反映されやすい setter + `InputEvent` 方式
- `キーボード入力風`: 厳しいサイト向け。選択中の文字を置き換える形で `insertText` を使う方式

設定画面では `Chrome候補抑制` も切り替えできます。有効時は、入力欄フォーカス中だけ `autocomplete="off"` などの属性を一時的に付けて、Chrome 標準の候補を出にくくします。フォーカスが外れたら元の属性へ戻します。

設定画面の一番上で、このサイトで機能を `有効` / `無効` に切り替えできます。無効にしたサイトでは、右下の `設定` ボタンだけ残り、候補表示・入力補助・Chrome候補抑制・履歴カウントは止まります。

## 候補の並び順

候補は次の順で表示されます。

1. 今開いているサイトで入力したことがある履歴
2. 使用回数が多いもの
3. 最近使ったもの
4. 手動で登録した候補リスト

履歴はサイト別に保存されます。例えば `example-a.com` でよく使ったマンション名は、`example-b.com` の履歴とは別に扱われます。

履歴カウントは、候補を入力欄へ入れただけでは増えません。フォーム送信、または `検索` / `決定` / `確定` などのボタンを押したタイミングで、その入力値をこのサイトの履歴として +1 します。

## 候補リストの編集

Tampermonkey の拡張機能アイコンから、このスクリプトのメニューを開きます。

- `設定画面を開く`: 候補と履歴を画面で管理する
- `このサイトで有効/無効を切り替え`: 現在のサイトだけ機能をオン/オフする
- `候補リストを編集`: 1行に1つずつ候補を入力
- `候補リストを初期化`: 手動候補を空に戻す
- `このサイトの入力履歴を削除`: 今開いているサイトだけ履歴を消す
- `すべての入力履歴を削除`: 全サイトの履歴を消す

候補名の右横のコピーアイコンで、入力欄への反映と個別コピーを同時にできます。コピーでは履歴カウントは増えません。

候補右側のゴミ箱で個別削除できます。`履歴` の候補は今開いているサイトの履歴から削除され、`候補` の候補は手動候補リストから削除されます。

## 注意

## 厳しいサイト向けの考慮

イタンジのように React/Vue などで入力欄を制御しているサイトでも反映されやすいように、値のセット時は通常の代入ではなくブラウザ標準の setter と `InputEvent` / `change` イベントを使っています。

また、iframe 内の入力欄でも動くように `@all-frames true` を付けています。Tampermonkey 側ではページ本体へ直接注入せず、content script 側で動く設定にしています。

日本語入力の変換中は候補表示を一時停止し、変換確定後に候補を出し直します。変換中に候補が動いて邪魔になるのを避けるためです。

通常の値セットが効かないサイトでは、設定画面の入力モードを `キーボード入力風` に切り替えてください。`document.execCommand('insertText')` を使って、よりキーボード入力に近い形で反映します。

このスクリプトの候補ポップアップと設定画面は Shadow DOM 内に作成します。サイト側の CSS の影響を受けにくく、逆にこのスクリプトの CSS がサイト側レイアウトへ影響しにくい構成です。

それでも以下のページでは動かない場合があります。

- Chrome ウェブストアやブラウザ設定画面
- 拡張機能の実行が禁止されている社内/業務システム
- ログイン後の一部画面が別ドメイン iframe で、Tampermonkey の実行許可がそのドメインにない場合
- サイト側が入力イベントを独自に検証し、通常のキーボード入力以外を拒否している場合
